Bible Memory Quiz
=================

Open index.html in a modern browser.

1. Click "Add / Import Text".
2. Enter a set name, reference, and the exact verse text you have permission to use.
3. Or use Bulk import: one verse per line in the format:
   Reference – verse text
4. Go to Quiz and type the requested verse from memory.
5. The app calculates a word-based score and shows a comparison.
6. Progress is saved in the browser's localStorage.

No server is required for this version.
